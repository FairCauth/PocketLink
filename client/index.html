高级设置

「系统麦克风」会自动选择虚拟声卡通道，无需手动选择。

多张网卡时，选择与手机同一网络的地址。

首次使用需安装 VB-CABLE。浏览器可能请求麦克风权限以读取设备列表，读取后立即停止采集。

设备改名：Windows 设置 → 系统 → 声音 → 输入 → CABLE Output → 重命名为「PocketLink 麦克风」。

iPhone 首次设置

手机扫码，用 Safari 打开并下载证书。已安装并信任过的手机可直接连接。

  1. Settings → Profile Downloaded → Install
  2. Settings → General → About → Certificate Trust Settings在 Enable Full Trust for Root Certificates 下开启对应证书。
  3. 返回 Safari，点击「打开麦克风」。
