# 使用指南

[返回 README](../README.md)

## 独立音频工作台

双击 **Start-PocketLink.cmd**，打开音频工作台。电脑独立使用、USB 和无线统一由这个入口启动，无需选择启动模式。首次会准备依赖、Apple USB 支持、虚拟声卡和电脑 HTTPS；已准备好的组件可复用。电脑音频处理和 USB 传输不需要热点或局域网，USB 手机无需证书。关闭时在启动窗口按 Ctrl+C。

在「麦克风输入」中选择设备并点击「开启麦克风」。看不到设备时点「刷新设备」，临时读取权限后立即释放采集；不会自动开启任何麦克风。选择「仅音效（无麦克风）」可直接播放音效，变声和音效板始终可用。

一条所选输入经过音量与变声处理，再与音效合成总输出。连接手机后列表新增「手机」，不会自动选中；切换输入会释放原电脑麦克风。所选手机断开或电脑设备拔出时停止该输入，不自动打开其他麦克风。关闭工作台会释放所有电脑采集。输出在设置中选择，电脑试听建议使用耳机。

需要连接手机时，点击工作台顶部「连接手机」，再选择 USB 有线或无线。

## Windows 一键启动

双击项目根目录的 **Start-PocketLink.cmd**。脚本会自动：

1. 查找 Node.js 22+；缺少时从 nodejs.org 下载免安装版本并校验 SHA-256，保存在 `.tools/`。
2. 安装缺少的项目依赖、从 mkcert 官方 GitHub 下载缺少的工具。首次准备需要联网。
3. 复用本机原有的 mkcert 根证书，检查电脑信任状态。首次安装电脑信任可能出现系统确认。
4. 检测当前网络 IP；网站证书缺少当前 IP、即将过期或不匹配时自动更新。
5. 配好 TLS 并启动服务，自动打开 <https://localhost:8787/receiver>。无需手动设置 `TLS_CERT` / `TLS_KEY`。

需要无线连接手机时，点击顶部「连接手机」，再点击「创建配对码」，选择任一种方式：

- **扫码直连**：用手机相机扫描电脑二维码，打开网页自动配对，需要手机输入时再开启麦克风，无需输入配对码。
- **手动配对**：手机打开电脑显示的网址，输入 8 位配对码，点击「连接」。

二维码随配对码刷新，切换网卡地址也会同步更新。扫码参数在手机打开后即从地址栏移除，刷新页面不会再次自动开启麦克风。若浏览器要求点击才能启用音频，会保留识别出的配对码，点击「连接」继续；拒绝麦克风权限或码已过期时也可重试。浏览器的麦克风授权和 HTTPS 确认仍由用户完成。

工作台始终显示麦克风输入、变声、音效和输出控制，手机连接为可选功能。音频输出设备和多网卡地址选择在右上角设置中。

保持启动窗口打开。停止时在启动窗口按 **Ctrl+C**。重复双击启动脚本会复用已运行的同一服务；网络变动时会重启本脚本管理的服务，原配对连接需重新建立。

旧版 `npm start` 启动的服务不受新停止脚本管理，第一次改用脚本前请先关闭旧服务。端口被其他进程占用时脚本会明确报错。

### iOS App 无需安装证书

使用 iOS 0.4.0 / Build 5 或更新版本，App 扫描新版电脑的无线配对二维码，自动校验并记住该电脑证书指纹。首次不要仅手动输入地址；电脑地址或证书更新后重新扫码。App 的输入麦克风列表与电脑同步，并标注手机为 USB 有线或无线。USB 输入配对码即可，无需手机证书。

### iPhone 网页版首次设置（每套根证书只做一次）

电脑接收端点击「首次使用 iPhone？」，用手机扫码，在 **Safari** 中打开设置页，点击「下载根证书」。页面使用单独的 HTTP 端口 8788，因此安装证书前就能打开。它只提供安装说明和公共根证书，不提供任何私钥。

1. 允许下载后：**Settings → Profile Downloaded → Install**，输入手机密码并完成安装。也可在 **Settings → General → VPN & Device Management** 找到已下载的描述文件。
2. 打开 **Settings → General → About → Certificate Trust Settings**，在 **Enable Full Trust for Root Certificates** 下开启对应证书。
3. 返回 Safari，点击「打开麦克风」，再输入电脑配对码。

如果手机已经信任这台电脑的 mkcert 根证书，直接使用即可。手机应安装的是 **rootCA 公共根证书**，不是 `pocketlink.pem` 网站证书。网页和电脑脚本不能替你完成 iPhone 系统里的安装、密码输入和开启完全信任。

**不必使用自带 Mail。** Safari 从网页下载即可，也可通过邮件或 AirDrop 传公共根证书。[Apple 描述文件安装说明](https://support.apple.com/en-us/102400)、[Apple 证书信任说明](https://support.apple.com/en-ie/102390)、[mkcert 官方 iOS 说明](https://github.com/FiloSottile/mkcert#mobile-devices)。

### 换网络 / IP 改变怎么办？

电脑和手机接入同一可互通网络后，**重新运行 Start-PocketLink.cmd**，再使用新的二维码和配对码。脚本在启动时检测地址，不会在后台持续监控网卡。

- **网站证书**：需要覆盖实际访问的 IP；新增 IP 时脚本自动重新签发，已覆盖则复用。
- **手机根证书**：只要电脑继续用原来的 CA 签发，换 IP、换 Wi-Fi、更新网站证书都无需在手机重新安装。
- 只有更换/丢失根 CA、根 CA 到期，或手机移除了信任，才需要重新处理手机端信任。

脚本把 CA 路径与指纹记在 `certs/authority.json`，防止不知情地换成另一套 CA。请保留原 mkcert CA 目录，**不要向手机或其他人发送 `rootCA-key.pem` 或网站私钥**。

有多张网卡或 VPN 时，在接收端「设置 → 高级设置 → 手机访问地址」切换。Windows 防火墙需要允许 Node.js 在所用的可信专用网络通信，包括 HTTPS 8787、首次设置 8788 及 WebRTC 音频。脚本不修改防火墙规则；防火墙弹窗出现时允许当前网络。路由器的访客隔离会阻止手机连接电脑。

可选命令：

```powershell
# 只检查环境、IP、是否需要更新证书，不启动服务
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Check
# 自定义端口、不自动打开浏览器
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Port 18787 -SetupPort 18788 -NoBrowser
```

## 一键启动的自动准备

日常使用双击 `Start-PocketLink.cmd`：

1. 查找 Node.js 22+；没有则从 nodejs.org 下载便携版，校验官方 SHA-256 后放入 `.tools`，不改系统 PATH。
2. 按 `package-lock.json` 安装依赖并准备网页资源。依赖清单变化、版本不符或缺失时重新安装；正常重复启动跳过安装。准备期间有文件锁，避免同时双击产生重复安装。
3. 检查 Windows 组件。缺少 Apple USB 支持时，通过 winget 的 Microsoft Store 源安装 Apple Devices；没有 winget 或安装失败时打开对应 Store 页面。缺少 VB-CABLE 时下载官方包，验证安装器数字签名并打开安装界面，用户点击 **Install Driver** 并同意系统授权。已安装或无法确定状态时不会重复安装。驱动就绪后会自动把录音端点 CABLE Output 改名为 PocketLink 麦克风；改名通过音频策略接口完成，无需管理员弹窗，已改好名则跳过。
4. 下载 mkcert、配置本机信任与服务器证书，启动服务，打开接收页。同一工作台支持电脑独立使用、USB 和无线；连接方式在界面内选择。电脑 HTTPS 不意味着 USB 手机需要安装证书。

首次下载需要联网；已经准备好的依赖与工具会复用。手机上的 **Trust**、网页版的根证书安装与信任需要在手机上操作；USB 直连无需开启个人热点。按照官方驱动安装器的要求重启 Windows，脚本不会自行重启。

下载或安装失败会显示具体错误。Apple/VB-CABLE 安装未完成时仍可启动网页服务用于无线连接或试听，但不声称 USB 或系统麦克风已经可用。当前 VB-CABLE 自动安装路径针对 x64 Windows；ARM64 请自行安装适配的音频驱动。运行日志保存在 `.runtime/startup.log`。

可选参数：

```powershell
# 自己管理驱动，只准备 Node/依赖/HTTPS 并启动
.\Start-PocketLink.cmd -SkipDrivers
# 检查环境，不下载安装、不启动服务
.\Start-PocketLink.cmd -Check
```

运行 `Start-PocketLink.cmd`，在「连接手机」中选择 USB 有线；默认工作台为 `https://localhost:8787/receiver`，USB 不需要热点或局域网。需要新版 iOS App，安装与验证状态见 [USB 指南](usb.md)。

## 三种连接方式

| 方式         | 必要条件                              | 音频路径                                 |
| ------------ | ------------------------------------- | ---------------------------------------- |
| 局域网       | 同一可互通网络；手机端可信 HTTPS      | WebRTC 点对点，不配置公网 ICE 服务       |
| 服务器       | 公开 HTTPS Node 服务 + 可用 TURN 服务 | 强制使用 TURN 中继的 WebRTC              |
| USB 原生直连 | Apple Devices + 数据线 + 新版 iOS App | Apple USB 通道承载 PCM 和控制；无 WebRTC |

USB 原生直连只接受数据线设备，不使用热点网卡或无线同步，也不会自动回退到无线。

运行 `Start-PocketLink.cmd` 后，电脑选择「连接手机 → USB 有线」创建配对码，App 选择 USB 并输入该码。旧版 App 需要重新编译更新。详细步骤和真机验收方法见 [USB 有线连接](usb.md)。

## 让会议软件使用处理后的声音

网页能接收和播放声音，但不能自行注册 Windows 系统麦克风。Windows 上安装一次 [VB-CABLE](https://vb-audio.com/Cable/) 即可供会议、游戏、OBS 等软件选择输入。音频路径是：所选麦克风 → 音量 / 变声 → 与音效合成 → CABLE Input → PocketLink 麦克风（原 CABLE Output）→ 其他软件。

1. 从官网获取 Windows 安装包，完整解压；64 位 Windows 右键 `VBCABLE_Setup_x64.exe` → **以管理员身份运行**，点击 **Install Driver**。按官方要求重启电脑。使用独立官方安装器；PocketLink 不捆绑或静默安装第三方驱动。
2. 启动 PocketLink，用电脑版 Chrome / Edge 打开接收页，在右上角 **设置 → 系统麦克风**。网页自动选择虚拟声卡通道，不必区分 Input / Output。需要听手机声音时，选择 **电脑试听**；手动设备选择在折叠的「高级设置」中。
3. 如浏览器请求电脑麦克风权限，允许即可。点击「系统麦克风」时，临时采集仅用于读取设备列表，随后立即停止；只有在主面板选择电脑输入并开启麦克风时才会持续采集。
4. 开启所选输入或播放音效，在会议、游戏或录音软件中，选择接收页设置中提示的麦克风名称：默认显示 **PocketLink 麦克风**；若初始化未能改名，则仍为 **CABLE Output**。接收网页须保持打开、播放且音量非零；手机静音和变声同样作用于其他软件。
5. 浏览器不能切换输出时，在 Windows 音量混合器里给该浏览器指定 **CABLE Input**。此系统设置可能把该浏览器其他标签页的声音也送入虚拟麦克风，优先使用页面内设备选择。

切换后电脑扬声器不播放手机声音是正常的，声音进入了虚拟麦克风。可在 Windows「设置 → 系统 → 声音 → 输入」选择 CABLE Output，讲话检查输入音量；接收页电平仅说明收到音频，不能证明系统路由成功。若软件未出现设备，安装后重启该软件或电脑。

初始化会自动将 VB-CABLE 的录音端点 CABLE Output 改成 **PocketLink 麦克风**，包括之前已经装好驱动的电脑。改名在当前用户进程中完成；若系统策略拒绝修改，会显示具体原因和手动改名路径，不会重复要求提权或重装驱动。播放端 CABLE Input、CABLE A/B、Voicemeeter 和真实麦克风不会改名。已显示 PocketLink 麦克风（带或不带驱动后缀）时跳过，不反复弹窗。刚安装尚未出现端点时按提示重启，再运行启动入口。网页本身不能改名；手动备用路径为 Windows 设置 → 系统 → 声音 → 输入 → CABLE Output → 重命名。改名后刷新浏览器或重新打开会议软件的设备列表。

驱动只需每台电脑安装一次，换网络和 IP 无需重装。接收页会记住「系统麦克风」模式，下次在同一浏览器、同一网址启用音频时先恢复输出；若权限或设备不可用，会提示重新设置，不会悄悄改用扬声器。选择「电脑试听」或其他输出会取消此偏好，隐私模式或禁止存储时无法保留。连接后会显示当前模式。本项目不修改系统默认音频设备。

## 电脑麦克风 + 手机遥控

在主面板选择电脑麦克风即可工作。按需配对原生 iOS App 或手机网页后，手机可遥控变声和音效；不需要开启手机录音。变声作用于当前选中的输入，App 音效和电脑音效保持原音。「麦克风音量」只影响所选麦克风，「输出音量」控制总输出。

连接手机不抢占电脑输入。手机断开、锁屏、取消或重新配对时，已开启的电脑麦克风和已经开始的音效继续运行，输出设备、音量和暂停状态不变。切换到电脑试听也不会停止采集；要停止请点「关闭麦克风」或关闭工作台。

需要手机输入时，在电脑选择「手机」并开启，在 App 或手机网页也开启麦克风。关闭电脑的输入只是断开其输出通道，实际手机采集应在手机端关闭。手机网页与 App 都通过独立控制通道遥控电脑音效和变声，不需要选择手机输入，也不需要录音权限。手机人声音轨保持原声（可在手机降噪），只在电脑对当前选中输入变声，避免重复处理。开启手机采集后，网页会提示电脑是否正在使用手机输入。

原生 App 的源码与安装步骤见 [iPhone App 指南](../ios/README.md)。本轮工作台更新不需要编译 App；USB 和后台采集仍需兼容版本与真机验收。

## 录音与隐私

手机网页的「电脑变声」始终可用作遥控，配对后与电脑同步所选效果；无需开启手机麦克风。改变它会处理电脑当前输入，不改变手机本地录音。电脑变声加载失败会恢复原声，手机页面同步结果与错误提示。

「手机录音」仅录制手机采集的人声（含手机降噪、静音和增益），不包含电脑变声、电脑麦克风或电脑播放的音效；未开启手机麦克风时录音按钮不可用。录音可回听、下载，断开连接后仍保留到页面关闭。

更新后重启服务、刷新电脑工作台和手机网页，再重新配对。手机网页仅支持无线连接，USB 仍使用原生 App。控制通道未就绪时不启用遥控按钮，不回退到手机本地混音。

- 手动打开手机首页不会采集；配对默认不采集手机麦克风。只有主动开启「使用手机麦克风」，才会请求权限并采集；拒绝权限不影响已配对的音效面板。
- 配对成功后才向电脑发送手机音频；配对失败、取消或断开连接都会释放手机麦克风。已手动开启的电脑麦克风独立运行，需在工作台点击「关闭麦克风」或关闭接收页来停止。
- Node 服务转发信令；局域网音频在设备间传输，服务器模式经 TURN 转发加密音频。服务不保存录音。
- 录音暂存在当前页面内存，刷新或关闭页面会丢失；请及时下载。每段最多 30 分钟或约 50 MB。
- iOS 锁屏、切换应用、电话打断可能暂停麦克风或网页。使用时保持页面在前台；可用时会请求屏幕常亮，但不承诺后台录音。
- 降噪、回声消除和实际采样率依赖浏览器与硬件；显示的往返延迟是 WebRTC 网络 RTT，不是完整的麦克风到会议软件延迟。

## 随时添加音效

在运行服务的电脑接收页打开 **音效板 → 添加音效**，可多选 MP3、WAV、M4A。单个文件不超过 10 MB，目录最多 50 个；追加保存、同内容不重复导入。上传后已配对的手机网页和 App 自动更新音效列表；App 音效栏也提供刷新按钮。添加音效不需要编译或重新安装 App。文件仍保存在电脑本地的 html/dist/sounds，手机只发播放指令。

音效上传功能需要本次更新后的 Node 服务，更新后先重启服务并刷新电脑接收页。为了避免局域网其他设备随意写入电脑，只能从运行服务的电脑直接访问并上传。

电脑麦克风列表会在设备插拔、窗口回到前台、打开设置时更新。新增设备不打断当前采集；拔出正在使用的设备会停止该路采集，需要手动选择并开启其他麦克风。

## 驱动管理

项目根目录仅保留启动和卸载两个入口：

| 入口                              | 作用                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `Start-PocketLink.cmd`            | 启动工作台，自动准备所需组件；已有 VB-CABLE 时检查麦克风改名 |
| `Uninstall-PocketLink-Driver.cmd` | 打开官方程序，点击 **Remove Driver** 卸载基础 VB-CABLE 声卡  |

卸载前关闭 PocketLink 接收页及使用这张虚拟声卡的会议、录音软件；共享的 CABLE Input / PocketLink 麦克风会同时移除，其他依赖 VB-CABLE 的软件也会失去这条音频路径。工具不卸载 Apple Devices、CABLE A/B、Voicemeeter 或其他声卡，不自动重启电脑。首次没有缓存时需要从官方站点下载驱动包。

工具会检查安装器签名，只有识别到基础 VB-CABLE 才打开卸载程序。系统不再检测到设备时才报告已移除；设备仍存在或检测失败时提示“卸载未确认”，可能是取消、失败或需要重启。卸载后再次双击启动程序，检测到缺少驱动会自动打开官方安装器，无需修复参数。旧版留下的禁止自动安装标记会在正常启动时清除；`-Check`、`-Stop`、`-SkipDrivers` 不安装驱动。已无驱动时卸载入口不会下载或启动安装器。

只检查状态（无改名或卸载）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\manage-cable.ps1 -Action Check
```

技术说明：通过 Core Audio 读取录音端点和适配器标识，再调用 Windows 10/11 的音频策略接口写入设备标签（DeviceDesc），由 Windows 生成完整显示名称，最后打开新的属性存储回读确认。不能直接通过 MMDevice 的 IPropertyStore 写入这些名称属性，管理员权限也不能解决该路径的 E_ACCESSDENIED。音频策略 IPolicyConfig 属于非公开接口，系统版本变化可能影响兼容性；失败时提供 Windows 声音设置的手动改名路径。不修改驱动 INF、驱动文件或注册表权限。参考 [Microsoft 设备属性说明](https://learn.microsoft.com/en-us/windows/win32/coreaudio/device-properties)及 [AudioDeviceCmdlets 的接口定义](https://github.com/frgnca/AudioDeviceCmdlets/blob/master/SOURCE/IPolicyConfig.cs)。卸载采用 [VB-CABLE 官方安装器](https://vb-audio.com/Cable/) 的 Remove Driver 界面。
